# Formulary Seal

This directory contains the sealed formulary input (`druglist.raw.txt`).

**Per Decision D14 and Ground Rule G14:**
- The formulary contents are SEALED until the final ingestion phase.
- No parsing, counting, summarizing, or deriving line-level claims is permitted.
- Irregularity CLASSES (combinations, multi-strength lines, unit variety, release markers, category mismatch) may inform parser DESIGN but no line-level specifics may be cited or embedded.
- The final ingestion phase requires: frozen schema, regulatory review or written user risk acceptance, tested parser.

**Owner:** Final ingestion phase (after hardening phases).
